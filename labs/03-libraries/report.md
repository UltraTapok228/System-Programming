# ЛР 3. Библиотеки программы

Система: Windows

## Библиотеки файла
- **Вывод программы:** `libs.exe: sqrt(2) = 1.414214`
- **Зависимости (`objdump -p libs.exe | findstr /i "DLL Name"`):** `KERNEL32.dll`, `msvcrt.dll`
- **Интерпретатор Python:** основной код находится в `python313.dll`, а `python.exe` выступает в роли пусковой обёртки.

## Библиотеки процесса
- **PID Python:** `7100` | **Модулей до ctypes.CDLL:** `44`, после: `45`
- **Загруженная библиотека:** `C:\Windows\System32\winsqlite3.dll`
- **Версия SQLite:** укажите вашу версию с 6-го скриншота (например, `b'3.53.4'`)
