# ЛР 4. Дерево процессов

Система: Windows

## Дерево
* **Корень:** `System Idle Process` (PID `0`), затем `System` (PID `4`)
* **Родители терминала:** `explorer.exe` (`13524`) → `cmd.exe` (`20904`) → `conhost.exe` (`11208`)
* **Дочерний процесс:** PID `24948` (родитель `20904`)
* **Команда проверки родителя:** `powershell -NoProfile -Command "Get-CimInstance Win32_Process -Filter \"Name='PING.EXE'\" | Format-Table ProcessId,ParentProcessId,Name"`
* **Браузер:** `14` дочерних процессов (`15` всего), имя процесса вкладок — `chrome.exe`

## Сирота
* **PID сирот:** `20572` и `16072`
* **Родитель (до/после):** `4256` (в Windows PID родителя не меняется после его завершения)
* **Позиция в дереве:** Внизу списка у левого края (на уровне `explorer.exe`), так как родительский процесс отсутствует в активных.
* *Примечание:* При прямом запуске проверки в PowerShell возникла ошибка из-за экранирования кавычек (`\"`), но в `cmd` команда отработала корректно.
