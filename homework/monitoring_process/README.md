# Заказ 04 — мониторинг процессов
Два способа проверки: 
1. `telemetry_sample.csv` — искусственные замеры процессов во времени.
2. `python run_workers.py` — запускает два **безопасных** тестовых процесса.

Напишите свой монитор, который раз в 1–2 секунды записывает время, PID,
название/командную строку, CPU и RSS-память, отмечает превышения порога.
Не завершайте процессы системы; для опыта используйте только процессы из лаборатории.

В CSV есть одинаковые имена, разные PID, перезапуск и постепенный рост RSS.
Проверьте, что монитор не путает завершившийся процесс с новым экземпляром.
`run_workers.py` ограничен по времени и объёму памяти.
